Streaming issues - Tool parsing during streaming is especially fragile

The Problem: Llama 3.2 3B is Too Small for Reliable Tool Calling
From vLLM's official docs:

"Llama's smaller models frequently fail to emit tool calls in the correct format. Your mileage may vary."

Specific Issues with Llama 3.2 3B:
No special tokens - Llama 3.2 emits no special tokens for tool call start/end, making parsing unreliable
Wrong parameter formats - Generates arrays as strings, missing commas, malformed JSON
No parallel tool calls - Only supported in Llama 4+
